## The Problem

Smart contract security monitoring is broken:
- Every tool runs on a single centralized server — one point of failure
- Alerts generated by one model with no second opinion
- Automated responses execute without consensus — wrong actions cost millions
- In 2024-2025, over 2.1B USD lost to exploits

**If your security layer can be taken down, it will be.**

## How It Works

1. WatcherAgent monitors Sepolia every 5 seconds automatically
2. Threat detected — ThreatProposal created with severity and evidence
3. ValidatorAgent-A and ValidatorAgent-B vote independently
4. ConsensusEngine evaluates 2/3 threshold
5. KeeperHub calls emergencyPause() on CerberusVault on-chain
6. 0G Galileo stores immutable audit log
7. Telegram alert with ENS agent identities

## Protection Layers

- Layer 2: CerberusGuard monitors Cerberus Protocol itself
- Layer 1: Cerberus Protocol monitors CerberusVault
- CerberusVault: Protected DeFi vault

"Who watches the watchmen? Cerberus does."

## Security Design

Built on real Code4rena audit experience (LayerZero x Stellar, High severity finding):
- No single agent decides — 2/3 consensus required
- Agents are stateless
- Audit log immutable on 0G
- Replay-resistant — unique proposal ID per round
- Real on-chain execution — not just webhooks
